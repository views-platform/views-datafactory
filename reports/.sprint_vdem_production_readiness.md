## Task 1: V-Dem NaN Propagation Tests (C-205, Tier 2)

**Why:** V-Dem country-year data has NaN values for countries/years where V-Dem has no coverage. If NaN propagates silently through the crosswalk → monthly expansion → compilation → assembly → grid, a model could train on NaN features without any error signal. This is the only Tier 2 item in the cluster.

**Register ref:** C-205

### Steps

1. In `tests/test_viewpoint.py` or a new `tests/test_vdem_viewpoint.py`:
   - Test that a V-Dem harvest Parquet with NaN values for one variable in one country-year produces NaN (not zero, not dropped) in the viewpoint output for all 12 months of that year.
   - Test that a country missing entirely from V-Dem (no ISO3 match in crosswalk) produces NaN for all V-Dem variables for that country's PRIO-GRID cells.
2. In `tests/test_compilation_vdem.py`:
   - Test that NaN values in viewpoint Parquet propagate as NaN to the compiled grid `.npy`.
   - Test that `np.isnan` on the compiled grid correctly identifies NaN cells.
3. In assembly:
   - Test that NaN values in a V-Dem compiled grid survive assembly into the full grid.

### Acceptance Criteria

- [ ] At least 3 NaN-specific test functions exist.
- [ ] Tests cover: viewpoint NaN passthrough, compilation NaN passthrough, crosswalk miss → NaN.
- [ ] All tests pass with `uv run pytest -k vdem_nan -v`.
